# Bounce Lite 0.2.1

日期：2026-10-01。标签：`v0.2.1`。本版定位为机制整合与体验打磨；三批功能及本次反向砖／脆砖微调已获用户验收。发布main源码与版本标签，不包含独立打包程序。

## 相比0.2.0

- 默认单球世界加入弹跳器、侧踢、斜面、平台、自动弹簧及碰撞驱动跷跷板，与原有转子／能量块共存。
- 运动采用1.5×速度、2.25×重力；弹簧持球0.20秒，并保留约50%有上限的来球横速。
- 加入低数量成对传送门，保留速度方向、独立冷却、防回跳和安全出口检查。
- 砖块共用一个机制族：脆砖一击碎，普通砖先裂再碎，反向砖首次拼合、再次更强地摔碎。反向砖采用普通碎片形状和柔和光晕。
- 本体通过共享占用接口默认双向避让，外围场力仍可自然交叠；支持未来实体明确允许重叠。
- 保留碰撞形变、声音层次、Vitality变暗，以及种子重开、组合保存／恢复和各阶段对照入口。

## 启动与组合

使用Godot 4.7 Compatibility，或配置路径后运行[run-playtest.bat](../../run-playtest.bat)。默认是几何／机械＋转子／能量块＋门户＋三类砖块。

| 入口 | 对照 |
| --- | --- |
| 默认 | 完整0.2.1累积世界 |
| `--no-bricks` | 门户版，无砖 |
| `--no-portals` | 几何＋原世界，无门户／砖 |
| `--geometry-only` | 纯几何 |
| `--geometry-baseline` | 原世界底座 |

R按种子重开、N换种子；F8保存组合，F9恢复并安全发球。默认组合外层v4、`world_mode=coexistence-bricks`、砖子格式v2；旧砖v1可恢复并保留原生成规则，R／N回到当前规则。门户v3等旧组合在对应入口打开，最近文件互不覆盖；快照不是球轨迹或输入录像。应用版本0.2.1与这些格式版本分别管理。

## 已知问题与后续打磨

- 各类实体出现概率仍需实验调整。当前脆／普通／反向权重60%／25%／15%，独立抽样可能连续两分钟没有反向砖，没有保底。
- 整体美术尚待加强，尤其反向砖外观；功能验收不等于美术定稿。
- F01／F05重新接入、F07底部循环、T01挡板侧向短暂重叠继续跟踪；F06净空效果仍保留体验复核。
- F04挡板移速传递、F08命中后加快离场仍未裁决；效果不佳的独立挡板亮边已撤下，后续UI/UX阶段再考虑。

本版不包含结构簇、默认多球、玩家抓球、积分、奖励或任务。后续在实验分支持续试玩并定向打磨，详见[当前计划](../exploration/harvest-refinement-plan.md#harvest-main-20261001)与[正式反馈登记](../exploration/toybox-playtest.md)。
