## 文档、测试与其他产物的生命周期

生成、保存和呈现为活跃是三个独立判断，不自动逐级晋升。对新增和已有对象都比较缺席或现实替代方案，说明实际损失、维护成本和承担者；“有用”“已经存在”“当时实现需要”均不足以自动取得长期位置。最小必要是完整承担职责的最小结构，不是文件或字数最少。

| 判断 | 应满足的条件 | 处理方式 |
| --- | --- | --- |
| 生成 | 当前判断、实现、交付或接续确有缺失，已有材料不能充分承担 | 优先修改权威内容；短任务可在对话说明，不例行新增方案、报告和索引 |
| 保存 | 有明确的复现、追溯、维护、来源或许可职责 | 保存职责所需的结论或原件；正式结论所需的基准、方法、关键结果和限制随仓库保留，完整本机日志可在忽略目录 |
| 活跃 | 当前任务确实依赖它，效力范围、维护者和依据可辨 | 在权威入口呈现，其他位置只链接；工具存在不表示每次必跑 |
| 退出活跃／维护 | 职责完成、被有效替代、依据失效，或仅剩追溯用途 | 停止同步和默认执行，移出当前入口；按剩余职责归档或移除，保留必要来源及替代关系 |

临时保留须有现实理由与退出条件，例如迁移仍依赖旧格式；不能以“以后可能用到”无限续期。已批准的长期方向可赋予过渡产物具体职责，一般未来可能性不足以支持新框架或兼容层。

### 测试不是实施过程的永久副产品

- **长期回归**保护当前有效契约、现实回归风险、支持中的兼容路径或开放缺陷；断言能识别实际错误，维护代价与风险相称。低频、未被总runner调用或名称较旧，都不能单独否定它。
- **复用诊断／捕获工具**须能回答仍会遇到的问题，输入、模式和输出可理解；按问题调用，不纳入默认回归以凑覆盖。保留依据是真实职责，不是文件前缀。
- **一次性探针**可以为实现或调查生成，但不自动进入长期测试集。问题结束后保存必要结果；若脚本无独立复用职责，退出工作树，历史版本供追溯。
- **重复或过时测试**先核对调用、独立断言、模式／初态、实际替代覆盖和删除损失。仅转发已有测试的包装、只改变输出位置的等价脚本，可合并入口；保护已退出行为的断言随对应行为退出，不能要求产品迎合它。
- 新增／实质修改测试时，实现代理说明拟承担的维护职责；任务收尾复核是否应长期保留。移除后验证受影响入口并保存必要依据。无需为每个测试建立另一个长期台账，也不定期无差别全量审计。
- 保存一次通过日志，不等于永远维护当时的捕获脚本；删除脚本，也不删除或重写已经取得追溯资格的证据。

### 决定、事实与证据

当前计划区分已明确选择、授权内暂定实现、未决候选和明确后置；实现／机器验证／代理观察／用户反馈是另一维度。两维不能相互晋升：已实现不等于永久决定，功能验收不等于美术定稿，受控可达不等于自然频率合适。

主代理维护活跃文档及替代关系；实现代理提供最终事实与证据；体验问题按用户对应反馈更新。文档替代时同步必要入口，不在多份历史材料顶部滚动复制最新状态。用户原稿、审查原稿和许可按来源保存，历史内部的“当前”“必须”“已授权”仅属于其时点。
