## 可玩底座

Godot 4.7、GDScript、Compatibility、960×720 逻辑视口与默认 640×480 窗口不变。整个客户区为场地，挡板中心 y=570。球、挡板、Vitality、E01 有限接触影响、中心色声画、转子与能量块共同构成底座。

挡板实际移动距离进入交互判断；目标位置变化但实体不动，不算有效动作。普通有效挡板碰撞恢复缺失 Vitality 的 30%。球的速度仍由 Physics 提交，状态通知和 Feedback 不反向改动运动。

## 随机对象

转子与能量块在 (72,72)–(888,465) 内随机生成；实体半径完整留在区域内，并排除球和其他对象附近。每次最多尝试32个位置，无合适位置延迟0.7秒再试。出现结束时再次检查球的位置。

开场转子延迟0.15–0.4秒、能量块0.9–1.6秒；出现与消退各0.65秒。转子停留16–25秒，能量块12–20秒；安全离场后1.2–3秒再生。转子等待球离开场力范围且余转降至0.35以内再消退；能量块等待球离开近邻。消退阶段不提供碰撞、旋转场或补能，图形随之消失。

转子保留半径24、场半径205、加速度上限105及碰撞记忆；能量块半径27、真实重叠补给0.32、冷却7.5秒，驻留重叠冷却后可再次补给。旋转场失效后不残留，基础微弱漂流仍存在。随机源可指定种子，最多保留256条对象生命周期记录。

## Wake 与 Continue

生命周期为 ACTIVE → DECAYING → RESTING → Wake 或 Continue → ACTIVE。两种启动都先提交运动、支撑与机会消耗，再通知 Activity。

| | Wake | Continue |
| --- | --- | --- |
| 发起 | 休息球附近的实际挡板运动 | 球停稳后自动消费已获得的一次机会 |
| 资格 | 原有水平范围200、短休息0.12秒、50ms采样内累计实际位移12.5 | 有效挡板接触；或球在空中、距挡板260以内、水平朝球累计移动4 |
| 时间 | 动作达阈值后立即 | 资格12秒内，连续停稳0.9秒后 |
| 向上速度 | 350 | 290 |
| Vitality 增量 | 最大值的30% | 最大值的18% |
| 表现 | 明显0.65秒扩散圈，球几何响应与升音 | 0.24秒近身向上线，短音更轻 |

Wake 消费旧 Continue 机会；Continue 只能用一次，新有效介入才能再获得。无输入不推断用户是否在场。起跳仍可能撞到挡板底面，既不穿透也不改起跳规避。
