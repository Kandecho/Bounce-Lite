# Bounce Lite V0.1 Core Gameplay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Project governance does not permit default subagent or worktree workflows. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable Endless prototype that proves the environment dissipates Ball energy, Paddle hits restore normal activity without infinite acceleration, and Paddle motion wakes a resting Ball.

**Architecture:** CharacterBody2D owns Ball movement and delegates scalar energy/state rules to a pure RefCounted model. Paddle input, Endless rules, procedural visuals, and HUD live in separate scripts connected by signals. A dependency-free headless test runner exercises deterministic rules and scene integration.

**Tech Stack:** Godot 4.7, GDScript, CharacterBody2D, Compatibility Renderer, Godot headless test execution.

**Spec:** `docs/superpowers/specs/2026-09-08-v0.1-core-gameplay-design.md`

## Global Constraints

- Endless only; no Game Over.
- No gravity; use a closed rectangular play area and deterministic reflection.
- Environment collision energy retention is never above `1.0`.
- Paddle top-face hit sets `current_energy = max_energy`; repeated hits never exceed the ceiling.
- ACTIVE / DECAYING / RESTING are derived from Energy.
- Wake requires sustained Paddle motion; micro-jitter must not trigger it.
- No Energy number/bar, leaderboard, formal art, formal fonts, formal audio, complex shader, or particles.
- Keep all tuning values in `PrototypeTuning`.
- Use TDD: write each behavioral test, observe the expected failure, implement the minimum, then run the complete suite.
- Work directly on local `main` because the user explicitly requested the current local repository and governance disallows default worktrees; do not configure a remote.

```gdscript
func speed_for_current_energy() -> float:
    var ratio := clampf(current_energy / max_energy, 0.0, 1.0)
    return minf(tuning.active_speed * sqrt(ratio), tuning.max_speed)

func restore_from_paddle() -> void:
    _set_energy(max_energy)

func apply_environment_collision(kind: SurfaceKind) -> void:
    var retention := _retention_for(kind)

```

```gdscript

    "active Ball starts at mapped speed")
```
