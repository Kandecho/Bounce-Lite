# Bounce Lite 物理电子玩具探索

日期：2026-09-12。来源：用户本轮开发方向与连续执行授权；整理与复核：Codex。

## 已确认方向

先完成上轮探索成果，验证并合入 `main` 作为新基线；随后把 Bounce Lite 当成没有预设目的的物理电子玩具。球、挡板、Vitality 和已有玩具构成底座，主动借鉴弹球和物理游戏机制，尽可能广泛地直接做成可玩的东西。设计理念在试玩后的筛选与改造阶段重新介入，不用于事前替用户收敛。

连续执行，只有重大风险、影响产品底层架构或新方向明确要求人工确认的事项才暂停。基线合入已获授权，不含远端推送、历史重写或把新一轮探索全部合入 main。机器检验、代理运行观察与用户试玩结论分别记录。

## 执行顺序

1. 完成 [V0.2.0 后续计划](v0.2.0-follow-up-plan.md)：随机对象生命周期、有效挡板动作资格、Wake/Continue 强弱与表现、完整场景检验及必要修正。
2. 本地合入 main，记录可返回提交与验证证据。
3. 从新基线创建实验分支，制作多种可直接切换与混合的物理玩法。开发入口服务试玩，不展开产品设置或发布包装。
4. 检验每种机制可触发、完整片段能持续演化、组合可退出和重置；交付试玩入口与具体机制说明。
5. 用户试玩后再筛选、组合、改造或淘汰，不以代码量决定保留。
