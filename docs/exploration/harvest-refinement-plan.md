# 当前打磨计划

基于0.2.1。持续产品约束见[概览](../project_overview.md)，实现细节及参数来源见[实现说明](../implementation.md)，逐项反馈见[问题登记](toybox-playtest.md#feedback-register)。

## 已明确选择

- 以单球为主要注意中心，在已整合的几何／机械、门户和砖块机制族内打磨；暂停广度扩张。
- 普通几何保持简单，通过可理解的碰撞丰富球路；弹簧自动持球、压缩、释放，跷跷板由碰撞驱动。
- 门户保持低数量、低频率而有存在感；砖块提供一击碎、裂后再碎、拼合后再摔碎三种短时动作。
- 在同一随机环境中持续试玩，允许自然组合；固定布局用于对照，不继续精修固定位置关系。

三批机制已实现并通过功能试玩，发布范围见[0.2.1](../releases/v0.2.1.md)。这不自动关闭开放问题，也不冻结表现与生成参数。

## 暂定实现

| 当前选择 | 依据及调整边界 |
| --- | --- |
| 运动尺度、弹簧持球时间与横速保留 | 已通过当前手感试玩，作为现用尺度；出现具体问题时仍可试调，精确值由共享tuning及几何模块维护 |
| 密度、寿命、生成间隔和砖种权重 | 实施阶段的试作选择；大致保留，结合实际空窗和球路调整，未选择防空窗策略 |
| 反向砖碎片与柔光、整体声画 | 交互已通过功能试玩，整体美术尤其反向砖仍需加强；可读性和听感需要实际体验 |

独立抽样允许反向砖出现较长空窗；一次种子出现完整动作，只能证明该条件下可达。空窗是否需要限制以及如何限制仍未决定。

## 下一步判断与候选

持续试玩重点看：想重新介入时是否有操作机会；对象能否被看见、理解并进入球路；空窗、重复往返和声画是否影响继续玩。反馈尽量带具体意图、时刻、种子或组合，不要求固定报告或最低试玩时长。

重新接入、循环、净空复核和挡板侧向重叠按问题登记跟踪。概率与美术是改进方向；挡板移速传递、命中后加快离场仍是候选，不能从问题成立直接推导解法已采纳。这些事项尚未排定实施先后。

## 明确后置

- 结构簇等待长期试玩暴露具体需要，再判断结构模板、随机组件与局部参数是否值得引入。
- 默认多球、临时分身—聚合、玩家抓球蓄力、结构自动聚合、通用对象延寿、世界编辑、自定义配方与创造模式后置；保留过的实验不自动成为默认功能。
- 额外场力不增加种类，以一次经过能否无需说明感到力的存在判断以后打磨价值。
- 独立挡板亮边留待UI/UX阶段重新考虑；全量设置和发布包装不是当前重点。

常规打磨在现有职责内推进，实质扩展范围再讨论。后续原型工作沿用实验分支，集成与发布按具体授权进行。
