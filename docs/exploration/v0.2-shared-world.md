# V0.2 共享小世界 — 完整可玩片段原型

状态：已实现，机器验证与主代理技术／视觉复核通过；整体体验待用户试玩。来源：用户已授权充分展开原型、允许自主视听修改，并要求主代理分派低推理子代理实现，优先可玩瞬间而非全量 UI。

分支：`codex/exp-v02-shared-world`；基准 E01 `b9a03f2`。E01 的有限接触影响已获用户实测认可，可保留；整个原型仍需体验。

## 体验目标

玩家通过有限接触影响球；球拨动一个真实可碰撞的转子，转子的余转改变局部气流。附近补能对象让下一段运动出现新的机会。球可以在互动中短暂停下并继续；较久的安静也可保留。声音和可见余波把共同作用连接起来。

这是整体创作假设，机制数量不构成验收标准。玩家可以接、等、试着靠近某件东西或停手，无需完成清单。场地与球保持注意中心，不做设置界面。

## 分工与最低接口约定

- 低推理核心代理：Ball 的显式世界加速度／活力接收／继续请求入口、停顿节奏、Main 接线和核心回归。
- 低推理世界代理：可碰撞转子、会恢复的补能对象、转子影响的气流与对应外观、世界场景测试。
- 低推理反馈代理：世界事件的声音与可见余波，来源记录和反馈验证。
- 主代理：文档与任务定义、分支管理、实际验证和返工分派，不写运行时或测试代码。

世界通过 `sample_acceleration(position, velocity)` 提供环境量，由 Ball 物理循环应用；通过 `vitality_offered(amount, position)` 通知真实区域接触，由显式入口提交活力结果。世界不写 Ball 的速度或位置。`event_emitted(kind, position, intensity)` 只供声音和视觉反馈。转子真实碰撞使用 Surface kind 4；响应完成后世界读取碰撞结果和位置延续转动。

## 现在可以经历的过程

- 接触仍保留 E01 的有限倾向，不把鼠标方向直接传给空中的球。普通挡板碰撞改为恢复缺失活力的 30%，给环境中的补能留下作用空间。
- 薄荷色转子是实际碰撞表面。球撞上后，转子留下会逐渐衰减的旋转；入射位置与速度影响方向和强度。转子附近的气流随后改变球的轨迹，风迹随余转变化。
- 琥珀色补能对象允许球穿过，实际重叠时提供 0.32 活力；耗尽后约 7.5 秒恢复。它不追逐球，不直接拉动轨迹，也不触发隐式启动。
- 最近 15 秒内有玩家输入时，物理停稳约 0.9 秒后可以继续一次。继续由物理入口提交向上 290 px/s 和 0.22 活力恢复；新输入才能再次提供这个机会，长期停手会安静下来。原有附近拨动与 Strong Wake 仍可使用。
- 世界事件有短促合成声音和扩散反馈；转子为薄荷色、补能为琥珀色、继续为青色。背景气流没有常驻声音。世界音效最多三声道，事件各自冷却，避免连碰时声音堆叠。

转子半径 24 px，局部气流半径 205 px、加速度上限 105 px/s²；重力沿用 260 px/s²，球速上限 520 px/s。转子的普通响应使用 0.94 弹性、法线方向 45 px/s 的额外弹起和缺失活力的 12% 恢复。近乎正中的径向撞击也允许转子余转，是有意的玩具化响应。数值和布置都是本原型的创作选择，不是用户确认的正式规格。

## 运行与对照

在此分支双击根目录 `run-playtest.bat`，或用 Godot 运行主场景，即进入完整原型。

| 操作 | 作用 |
| --- | --- |
| 鼠标左右移动 | 移动挡板，接触或在附近拨动球 |
| F5 | 静音／恢复基础和世界两组声音 |
| F7 | 切换未来接触的 E01 有限影响，保留当前世界和运动历史 |
| F1 | 默认隐藏的开发调参和过程计时 |
| Godot 参数 `-- --v02-baseline` | 不创建世界和世界反馈，关闭停顿继续，恢复原挡板补能比例；仍保留 E01 |
| Godot 参数 `-- --v02-baseline --e01-baseline` | 再关闭 E01，使用 V0.1.6 接触规则作比较 |

命令行参数传给 Godot 本身，现有双击启动器不转发这些对照参数。对照使用同一开局；运行中的 F7 不会复原已经分化的轨迹。两种对照都包含本轮的夹墙和浅地面碰撞修复，因此不是历史提交的逐字节复现；严格历史对照应使用保留的 E01 分支或 V0.1.6 基准。后续若要精确拆解单项机制，可以继续在此分支上增加有针对性的开关，不预建设置界面。

## 待体验与反向分析

完整组合尚未获用户体验验收。机器可确认事件可达、运动边界和资源生命周期，不能确认伙伴感或停留意愿。固定的对象位置、继续条件和声音都是第一版选择；过去的高速横扫限制并未自动变成全输入保证。

已发现的体验取舍：持续把挡板留在地面球的正上方，继续会真实撞到底面；持续移动又会重新提供继续机会，容易形成重复的短弹起。主动让出空间后可以重回较长的往返。是否需要让“继续”等待空间、改变它的运动表达或取消这一行为，留待用户真实体验后的反向分析；不为增加事件计数让球穿过挡板。

试玩先自由停留几分钟，不要求逐项完成。之后围绕具体瞬间判断：转子的余波是否让人想接着回应；补能是共同关注还是分散注意；停顿后继续是否留住互动；声画是帮助理解刚才的共同作用，还是仅仅热闹。

下一轮依据实际片段决定保留、变形或搁置，再移除或替换对应元素。E01、main 和本分支都保留可返回基准；本轮不合入 main，也不推送远端。
