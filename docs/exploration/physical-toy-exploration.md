## 用户试玩后的收获与决定（2026-09-16记录）

用户确认增加几何／机械实体后，世界明显更丰富；球能在空中与结构发生连续碰撞，运动也更多样。普通几何已经成立，值得继续打磨。广度阶段产出的是可筛选、可发展的玩具候选，而非需要回退纠正的失败方案。

| 候选 | 用户试玩后的方向 |
| --- | --- |
| 几何／机械 | 确认值得第一批harvest；弹簧与自动周期摆板的特殊性仍弱，本轮改清楚自身动作 |
| 传送门 | 确认值得后续集成；保持第二批，当前不迁移 |
| 砖块 | 确认值得作为独立设计空间发展，普通砖与反向砖仍属第三批 |
| 多球 | 默认多球不进入新基线，未来更适合作为短暂事件候选 |
| 抓球蓄力 | 有潜力，暂时后置，保留探索成果 |
| 场力 | 保留为可感知性refinement候选，先判断球经过后能否不看说明感到力；不立即淘汰或继续增加种类 |
| 结构簇 | 当前几批集成完成并再次长期试玩后，依据真实问题判断是否引入 |

新的上位判断是 **“没有意义的好玩”**：玩的行为本身可以成立，不需要积分、任务、奖励或长期收益提供外部意义。基础机关通过清楚的物理行为丰富球的运动，不要求每种机关留下痕迹、拥有长期状态或承担Toy Partner的人格表达。

9月16日至22日第一批处理了弹簧“抓住—压缩—释放”、碰撞驱动跷跷板、底部及挡板横向路径的实体净空、平台真实支撑期间暂缓离场、去掉机关附带Vitality补能。9月23日进一步把基础手感问题纳入[正式反馈登记](toybox-playtest.md)，速度参数的分散与耦合详见[调查记录](geometry-harvest-batch1.md#motion-investigation-20260923)。问题吸收不表示原始候选解法全部获采纳；密度与寿命不在本次文档工作中改变。

## 广度阶段已确认方向（历史）

下方low代理分工与主代理独立验证均为历史时点；当前模型、文件所有权、审查边界和证据要求以[代理执行纪律](../../AGENTS.md#agent-execution-policy)为准，不从历史记录恢复统一low或例行重复验证。

先完成上轮探索成果，验证并合入 `main` 作为新基线；随后把 Bounce Lite 当成没有预设目的的物理电子玩具。球、挡板、Vitality 和已有玩具构成底座，主动借鉴弹球和物理游戏机制，尽可能广泛地直接做成可玩的东西。设计理念在试玩后的筛选与改造阶段重新介入，不用于事前替用户收敛。

连续执行，只有重大风险、影响产品底层架构或新方向明确要求人工确认的事项才暂停。基线合入已获授权，不含远端推送、历史重写或把新一轮探索全部合入 main。机器检验、代理运行观察与用户试玩结论分别记录。

2026-09-13补充：主代理集中于提出方向、看结果、判断和重派，不大量巡检或重复执行全部检查。默认视图由代理选择、组合并实现最值得展示的一批机制，其他内容留作探索记录或可选切换；这不等于提前替用户做最终筛选。

同日后续补充：固定布局达到可玩后立即保留为确定性对照，下一轮重点是玩具随机出现、随机停留、消失，允许多个玩具同时存在并通过物理自然形成组合。不要预设组合的正确结果，也不要为了避免奇怪互动隔离玩具；仅保证生成基本合法，并尽量保留某次组合的可复现信息。

### 已完成的探索批次（2026-09-13）

在 `codex/exp-physical-toybox` 上进行。第一批把抓球蓄力抛出、弹跳器、可击碎靶、磁场与成对传送门组合起来，以两球开场；固定游乐场已可玩并保存为 `6f31ea7`。`--toybox-fixed` 保留这一布置，`--toybox-baseline` 保留完整V0.2.0底座。

弹跳器组合、砖与小靶、磁场与传送、机械组合、挡板试验以及独立碰撞／场力切换保留为可选入口，不要求用户先挑选模式才能开始玩；这些入口也不作为后续必须保留的产品模式。

并行分工：low 碰撞代理负责弹跳器、三角侧踢、两段砖、小靶、弹簧与摆动板；low 场力代理负责磁场极性、风道、加速环、传送、阻尼与升力区域；low 核心代理负责明确物理请求接线、多球、抓取／蓄力抛球、接触横速传递、重力与慢速变量、切换／混玩入口和综合验证。主代理审查与实际检查，不代写实现。

独立模块通过加速度采样、接触响应请求与空间转移请求进入 Ball 的物理提交。没有更换物理引擎、重建状态机或预建通用架构。基线0保留原有随机转子与能量块；多球探索布置暂不启用原共享世界，避免原单球补能广播误授予其他球。

接续阶段已将默认入口改为随机游乐场。六类实体玩具与七类场力机制随机出现、停留、离场，允许同类并存与场力重叠；最多6个实体与4组场力只用于限定资源。实体生成排除越界、球、挡板及实际实体重叠，场力不形成禁区。没有逐组合安排正确路线，也没有为消除奇怪互动隔离机制。

种子、生命周期事件和JSON快照提供重访能力。快照恢复玩具组合、剩余寿命与随机源进度，然后安全重新发球；不宣称复原原始输入过程。随机对象进入挡板活动区域后，还发现并修复了持球随动穿过实体的问题：抓住球和随挡板移动都经过碰撞检测，受阻时保留实际球位置。固定位置关系未继续精修。

该阶段按键、参数、机器验证、真实渲染与复现边界见[游乐场试玩记录](toybox-playtest.md)。广度游乐场已完成用户实际试玩，其收获和筛选决定已补入本文上方；当前待试玩的是第一批refinement后的动作和参数，不能继续把全部随机阶段记为“尚未试玩”。旧理念文档保留历史来源与基线语义。
